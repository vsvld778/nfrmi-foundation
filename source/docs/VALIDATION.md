# Проверка сайта фонда

Дата проверки — 11 ноября 2026 года. Проверены производственная сборка, типы TypeScript и серверные обработчики с реальной SQL-схемой. Браузерная проверка и интеграционные запросы к размещённому Cloudflare Worker на этом этапе не выполнены.

## Сборка и типы

| Проверка | Результат |
| --- | --- |
| `npm run db:generate` | Создана миграция `drizzle/0000_whole_stone_men.sql` и метаданные Drizzle; 8 таблиц |
| Сборка через `sites/1.1.6/scripts/build-site.mjs` | Успешно; Vinext собрал публичные страницы, панель и API |
| `tsc --noEmit --pretty false` | Успешно, ошибок типов нет |
| Производственный код авторизации | Условие локального доступа в режиме разработки скомпилировано в `false`; строка `local_seedy` отсутствует в производственной ветке авторизации |

Сборка и итоговая проверка типов выполнены с обычным Node.js 22.16.0 для macOS arm64. Первая попытка сборки встроенным Node.js приложения не смогла загрузить нативный модуль Rolldown из-за несовпадения подписей macOS; после использования обычного Node.js сборка завершилась успешно. Политики безопасности системы не изменялись.

## Проверки серверных обработчиков

Временный проверочный стенд напрямую вызвал исходные обработчики маршрутов, выполнил SQL из миграции в SQLite и использовал адаптер с интерфейсом D1. Хранилище R2 и контекст вошедшего пользователя были заменены контролируемыми тестовыми реализациями. Проверка выполнена на Node.js 24.22.1 с встроенным `node:sqlite`, с производственным значением `import.meta.env.DEV = false`.

Все 23 проверки завершились успешно:

1. Анонимный административный запрос отклонён с 401.
2. Вошедший пользователь без разрешения получает 403.
3. Производственный режим не даёт права локальной тестовой учётной записи.
4. Пустой `ADMIN_USER_IDS` запрещает административный доступ.
5. Миграция исполняется, начальное заполнение создаёт 25 записей.
6. Изменяющий запрос с чужим `Origin` отклоняется.
7. HTML в содержимом отклоняется серверной проверкой.
8. Черновик отсутствует в публичном списке и недоступен по slug.
9. После публикации материал появляется в публичном списке.
10. Сохранение устаревшей версии материала получает 409.
11. Опубликованную запись нельзя удалить до архивирования.
12. Старый slug разрешается в актуальную опубликованную запись.
13. Исходная статья с семантическим значением `meta.image` сохраняется через API.
14. Настройки сохраняются, устаревшая версия настроек отклоняется.
15. Отсутствие согласия и неверная контрольная сумма ИНН отклоняются.
16. Заявка сохраняется один раз; повторная отправка возвращает тот же номер.
17. Повторное использование ключа отправки с другим содержимым получает 409.
18. Администратор изменяет статус и заметку; устаревшая версия заявки отклоняется.
19. CSV-экспорт экранирует формульное значение.
20. Загруженный файл без публикации доступен администратору и скрыт от анонимного посетителя.
21. Публикация документа открывает файл, архивирование снова закрывает публичный доступ.
22. Файл с MIME PDF и фактическим HTML-содержимым отклоняется.
23. Журнал фиксирует действия и не содержит полей с полным текстом заявки или email.

Тестовые обращения и файлы существовали только в памяти проверочного стенда. Они не добавлялись в производственную базу или начальное наполнение.

## Ограничение локальной проверки

После успешной сборки была запущена штатная локальная команда Wrangler для применения миграции. Она завершилась ошибкой `listen EPERM: operation not permitted 127.0.0.1`: среда выполнения не разрешила открыть локальный сетевой слушатель. Локальная миграция этой командой не применена, сервер предварительного просмотра не запущен. Ограничение не обходилось.

Проверочный стенд подтверждает логику обработчиков и SQL, но не заменяет работу настоящих D1, R2, входа через ChatGPT и браузерных форм на размещённом сайте. Проверка перенаправления со старого slug в стенде охватывает поиск канонической записи, а не HTTP-ответ публичной страницы.

## Проверки после размещения

Необходимо проверить вход владельца, реальный список `ADMIN_USER_IDS`, сохранение через административную панель и повторное открытие на другом устройстве, формы и приватность файлов на Cloudflare, а также мобильные ширины 360, 390, 768 и 1280 px. Отдельно проверяются клавиатура, контраст, прямые переходы, 404, фильтры и отсутствие черновиков в публичной навигации. Успешное прохождение этих проверок в этом документе пока не утверждается.


## Проверка опубликованной закрытой версии

В браузере подтверждены: вход владельца через ChatGPT; отказ до назначения административной роли; доступ к панели после установки allowlist; сохранение автора материала; отправка вымышленной тестовой заявки с номером; появление заявки в админке; сохранение статуса «Завершена» и внутренней заметки. Тестовая заявка явно помечена как тестовая и оставлена в завершённых.

Проверены мобильные размеры 360 и390px. В панели при390px ширина документа равна viewport, боковое меню закрывается. Обнаружена несовместимость клиентского Link в текущем Vinext: переходы заменены стандартной навигацией браузера, которая также работает без JavaScript.
