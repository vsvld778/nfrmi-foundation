## Границы проверки

Проверка размеров выполнена в Safari на Mac, а не на физических телефонах. Chrome, Firefox, экранный диктор и эмуляция плохой сети не проверялись. В этой итерации не повторялись загрузка файлов, удаление записей и полный цикл публикации материалов: соответствующая серверная логика не менялась. Локальный dev-сервер не запустился из-за `listen EPERM 127.0.0.1`; визуальные и функциональные проверки выполнены на опубликованном сайте.

На GitHub Pages публикуется статическая копия публичных страниц; форма и панель управления работают на основном сайте. Их серверные данные в GitHub не экспортируются.
