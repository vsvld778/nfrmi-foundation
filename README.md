Публичный сайт Национального фонда развития и международной интеграции (ИНН 7725234866).

- **GitHub Pages:** https://vsvld778.github.io/nfrmi-foundation/
- **Основной сайт и форма обращения:** https://nfrmi-foundation-vsevolod.nordterma.chatgpt.site/
- **Панель управления:** https://nfrmi-foundation-vsevolod.nordterma.chatgpt.site/admin

## Что опубликовано

`docs/` — готовые статические страницы для GitHub Pages: главная, сведения о фонде, история, направления и их описания, проекты, регионы, материалы, документы, контакты и политика обработки данных. Сохранены оформление, адаптивная вёрстка, поиск и фильтры каталогов. В разделе проектов и документов отображается фактическое состояние публикаций в CMS.

`source/` — исходный проект основного сайта: Vinext / React, серверная панель управления, API, миграции D1 и интеграция с R2. Это копия исходников без учётных данных, содержимого базы, обращений и локальных файлов среды разработки. Серверная часть зависит от платформенного окружения Sites и авторизации ChatGPT; GitHub Pages её не запускает.

Кнопки обращения и входа администратора ведут на основной сайт. Приём обращений, авторизация, база данных и загрузки документов работают на его сервере. На GitHub нет имитации отправки формы и нет копии данных заявителей.

## Обновление публикации

Pages — снимок опубликованного содержимого основного сайта. Сохранение в админ-панели сразу обновляет основной сайт; для обновления GitHub Pages требуется повторный экспорт и коммит. Автоматической синхронизации CMS с GitHub сейчас нет.

Нужны Node.js 22+ и Python 3.9+; дополнительных пакетов для экспорта нет.

```sh
node scripts/fetch-public.mjs --cache .cache/public
python3 scripts/export-static.py --cache .cache/public
```

Загрузчик запрашивает только публичный sitemap, HTML и открытые ресурсы без входа в учётную запись. На каждый запрос установлен тайм-аут 20 секунд. Экспортёр удаляет серверные скрипты и служебные данные, переносит метаданные страниц в `head`, корректирует адреса для `/nfrmi-foundation/` и проверяет локальные ссылки. Неполный снимок или ошибка проверки не заменяют существующий `docs/`.

Перед публикацией проверьте изменения, затем закоммитьте `docs/` и отправьте их в `main`. GitHub → Settings → Pages: **Deploy from a branch**, ветка **main**, папка **/docs**. Файл `.nojekyll` обязателен для ресурсов в `_next/`.

Исходники в `source/` не обновляются выгрузкой HTML: изменения серверного приложения нужно отдельно переносить из исходного проекта. Не добавляйте в репозиторий `.env`, `.wrangler`, локальную базу, ключи доступа и выгрузки обращений.

## Материалы и ограничения

- Экспорт отражает публичное содержимое CMS на дату в `docs/export-manifest.json`.
- На GitHub сохранена текущая редакция страницы обработки данных основного сайта, включая её статус тестового проекта документа.
- Снятие материала с публикации на основном сайте не удаляет уже опубликованный снимок GitHub. Для этого нужен новый экспорт и коммит.
- Изображение офисной архитектуры иллюстративное; происхождение указано в `source/docs/ASSETS.md`.
- Open Sans распространяется по SIL Open Font License: `docs/fonts/OFL.txt`, `source/public/fonts/OFL.txt`. Уведомления о лицензиях компонентов сохранены вместе с исходниками.
