Условия работы с обращениями

Текущая версия сайта предназначена для закрытой проверки. Используйте в форме только вымышленные тестовые сведения. До начала публичного приёма обращений фонд разместит утверждённые условия обработки персональных данных, сроки хранения и контакт для обращений. Тестовые обращения доступны только уполномоченному администратору и используются для проверки работы сайта.
